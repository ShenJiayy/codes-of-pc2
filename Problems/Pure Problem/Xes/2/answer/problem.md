# U705928 最小差值 II

## 题目描述

现有两个序列 $a, b$，长度分别为 $n, m$。

求 $\min |a_i-b_j| (1 \leq i \leq n, 1 \leq j \leq m)$。

## 输入格式

$n$ $m$

$a_1 \dots a_n$

$b_1 \dots b_m$

## 输出格式

$ans$（代表答案）

## 输入输出样例 #1

### 输入 #1

```
2 2
1 6
4 9
```

### 输出 #1

```
2
```

## 输入输出样例 #2

### 输入 #2

```
6 8
82 76 82 82 71 70
17 39 67 2 45 35 22 24
```

### 输出 #2

```
3
```

## 说明/提示

$$
1 \leq n, m \leq 2 \times 10 ^ 5\\
1 \leq a_i, b_j (1 \leq i \leq n, 1 \leq j \leq m) \leq 10 ^ 9
$$
