# U705844 差之和

## 题目背景

目前暂无测试数据。

明天补。

## 题目描述

现有两个序列 $a, b$，长度分别为$n, m$。

求
$$
\sum_{i=1}^{n} \sum_{j=1}^{m} |a_i-b_j| \mod 998244353
$$

## 输入格式

$n$ $m$

$a_1 \dots a_n$

$b_1 \dots b_m$

## 输出格式

$ans$（代表答案）

## 输入输出样例 #1

### 输入 #1

```
4 2
1 6 9 2
3 1
```

### 输出 #1

```
26
```

## 输入输出样例 #2

### 输入 #2

```
8 8
185991676 311812083 311812083 84357963 185991676 185991676 724020528 369175631
455049197 387671868 4361724 724020528 724020528 455049197 455049197 724020528
```

### 输出 #2

```
529117255
```

## 说明/提示

### 说明

样例1：

$|1−3|+|1−1|+|6−3|+|6−1|+|9−3|+|9−1|+|2−3|+|2−1|=2+0+3+5+6+8+1+1=26$

### 数据范围

$$
1 \leq n, m \leq 3 \times 10 ^ 5\\
1 \leq a_i, b_j (1 \leq i \leq n, 1 \leq j \leq m) \leq 998244353
$$
