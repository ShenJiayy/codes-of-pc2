# POJ1850 - Code
## 题目描述
一个众所周知的系统是将数字与字符序列相关联的系统。据认为单词仅由英语字母表中的小写字符a，b，c，…，z（26个字符）组成。从所有这些单词中，我们仅考虑那些字母按字典顺序排列的单词。
该单词中的每个字符都严格小于下一个字符。

编码系统的工作原理如下：

- 单词按长度递增的顺序排列。
- 具有相同长度的单词按字典顺序排列。
- 我们通过它们的编号对这些单词进行编码，从`a`开始，如下所示：
```plain
a 	- 1   
b 	- 2
...
z 	- 26
ab 	- 27
...
az 	- 51
bc 	- 52
...
vwxyz 	- 83681
...
```
对于给定的单词，请指定它是否可以根据这个编码系统进行编码。
如有，请指定其编码。
如无，输出 `0`。

## 输入格式
1行。
包含一个单词。单词最长为10个字母，且全部为小写字母。

## 输出格式
1行。
给定单词的对应编码，如果该单词无法进行编码，则输出 `0`。

## 样例 #1
### Input
```
bf
```
### Output
```
55
```

## 提示
该单词中的每个字符都**严格小于**下一个字符。
如果该单词无法进行编码，则**输出 `0`**。
