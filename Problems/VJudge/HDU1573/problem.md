# HDU1573 - X问题
## Desription
求在小于等于$N$的正整数中有多少个$X$满足：$X \mod a_i = b_i(0 < a_i \le 10)$。
## Input
输入数据的第一行为一个正整数$T$，表示有$T$组测试数据。每组测试数据的第一行为两个正整数$(N，M)$ $(0 < N \le 10^9 , 0 < M \le 10)$，表示$X$小于等于$N$，数组$a$和$b$中各有$M$个元素。接下来两行，每行各有$M$个正整数，分别为$a$和$b$中的元素。
## Output
对应每一组输入，在独立一行中输出一个正整数，表示满足条件的X的个数。
