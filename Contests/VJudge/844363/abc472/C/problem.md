## C - 节食

得分：$300$ 分

### 题目描述

高桥正在父母家进行为期 $N$ 天的探亲之旅。

在他父母家，每天都会准备一份零食，第 $i$ 天的零食热量为 $A_i$。

为了保持健康，他遵循以下规则：只有当最近 $M$ 天内所吃零食的总热量不超过 $K$ 时，他才在第 $i$ 天吃该零食。

具体来说，按顺序 $i=1,2,\dots,N$，他根据以下规则决定是否在第 $i$ 天吃零食：

-   假设他在第 $i$ 天吃零食，如果从第 $\max(i-M+1,1)$ 天到第 $i$ 天所吃零食的总热量不超过 $K$，则他确实会在第 $i$ 天吃零食。否则，他不会在第 $i$ 天吃零食。

对于每个 $i=1,2,\dots,N$，判断高桥是否会在第 $i$ 天吃零食。

### 约束条件

-   $1 \leq M \leq N \leq 2 \times 10^5$
-   $1 \leq K \leq 10^{15}$
-   $1 \leq A_i \leq 10^9$
-   所有输入值均为整数。

* * *

### 输入

输入通过标准输入以以下格式给出：

```
$N$ $M$ $K$
$A_1$ $A_2$ $\dots$ $A_N$
```

### 输出

输出 $N$ 行。第 $i$ 行应包含 `Yes`（若高桥在第 $i$ 天吃了零食），否则包含 `No`。

* * *

### 输入示例 1

```
5 3 83
48 73 59 90 21
```

### 样例输出 1

```
Yes
No
No
No
Yes
```

对于每一天，假设他吃了零食，最近三天所吃零食的总热量如下：

-   第 $1$ 天：$48$
-   第 $2$ 天：$48+73=121$
-   第 $3$ 天：$48+59=107$
-   第 $4$ 天：$90$
-   第 $5$ 天：$21$
