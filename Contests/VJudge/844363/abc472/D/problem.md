## D - 炸弹狂人

得分：$400$ 分

### 题目描述

有一个由 $H$ 行和 $W$ 列组成的网格。每个单元格要么是空单元格，要么是炸弹单元格。 设 $(i,j)$ 表示从顶部数第 $i$ 行、从左侧数第 $j$ 列的单元格。该网格由 $H$ 个长度为 $W$ 的字符串 $S_1, S_2 , \dots ,S_H$：如果 $S_i$ 的第 $j$ 个字符是 `.`，则 $(i,j)$ 是一个空单元格；如果 $S_i$ 的第 $j$ 个字符是 `#`，则 $(i,j)$ 是一个炸弹单元格。

对于空单元格 $(i,j)$，如果 $i$ 行和 $j$ 列中均不存在炸弹单元格，则该单元格被称为 **安全空单元格**。

在一次移动中，你可以从当前格子沿上、下、左或右方向移动到相邻的空格（不能移动到炸弹格）。求满足以下条件的空格 $(i, j)$ 的个数：

-   从 $(i, j)$ 出发，最多经过 $K$ 步即可到达一个 **安全空格**。

### 约束条件

-   $1 \le H, W \le 5\times 10^5$
-   $H \times W \le 5 \times 10^5$
-   $0 \le K \le H \times W - 1$
-   $S_i$ 是一个长度为 $W$ 的字符串，由 `.` 和 `#` 组成。
-   $H$、$W$ 和 $K$ 均为整数。

* * *

### 输入

输入通过标准输入按以下格式给出：

```
$H$ $W$ $K$
$S_1$
$S_2$
$\vdots$
$S_H$
```

### 输出

输出满足该条件的空格数量。

* * *

### 输入示例 1

```
3 3 1
#..
...
..#
```

### 样例输入 1

```
5
```

唯一的 **安全空格** 是 $(2,2)$。 有五个空格，从这些空格出发最多只需一步即可到达 $(2,2)$：$(1,2),(2,1),(2,2),(2,3),(3,2)$，因此答案是 $5$。

* * *

### 样例输入 2

```
2 3 0
...
...
```

### 示例输出 2

```
6
```

由于没有炸弹格，所有六个格子都是 **安全的空格**。因此，每个空格都能在零步内满足条件。

* * *

### 示例输入 3

```
5 7 2
..#....
..#....
.......
...#...
...#...
```

### 示例输出 3

```
29
```
