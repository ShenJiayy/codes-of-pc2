## E - 奇数周期

得分：$450$ 分

### 问题陈述

给定一个单连通无向图，该图有 $N$ 个顶点，编号从 $1$ 到 $N$，以及 $M$ 条边。第 $i$ 条边连接顶点 $a_i$ 和 $b_i$。

判断是否存在由奇数个顶点组成的环；若存在，则找出这样一个环。

严格来说，判断是否存在一个整数序列 $(v_1,v_2,\ldots,v_K)$ 满足以下所有条件；若存在，则找出这样一个序列。

-   $K$ 是至少为 $3$ 的奇数。
-   $v_1, v_2, \ldots, v_K$ 互不相同。
-   对于每个满足 $1 \le i \le K$ 的整数 $i$，顶点 $v_i$ 与 $v_{i+1}$ 之间存在一条边，其中 $v_{K+1} = v_1$。

给你 $T$ 个测试用例；请分别求解每个用例。

### 约束条件

-   $1 \le T \le 2\times10^5$
-   $1 \le N, M \le 2\times10^5$
-   所有测试用例中 $N$ 的总和不超过 $2\times10^5$。
-   所有测试用例中 $M$ 的总和不超过 $2\times10^5$。
-   $1 \le a_i,b_i \le N$
-   $a_i\ne b_i$
-   给定的图是一个单连通无向图。
-   所有输入值均为整数。

* * *

### 输入

输入通过标准输入以以下格式给出：

```
$T$
$\mathrm{case}_1$
$\mathrm{case}_2$
$\vdots$
$\mathrm{case}_T$
```

每个测试用例的格式如下：

```
$N$ $M$
$a_1$ $b_1$
$a_2$ $b_2$
$\vdots$
$a_M$ $b_M$
```

### 输出

对于每个测试用例，若不存在满足条件的序列，则输出 `-1`。若存在，则按以下格式输出一个这样的序列：

```
$K$
$v_1$ $v_2$ $\ldots$ $v_K$
```

如果存在多个满足条件的序列，输出其中任意一个即可。
