## E - 求和平方和

得分：$450$ 分

### 问题陈述

有 $N$ 个球，编号从 $1$ 到 $N$。球 $i$ 上标有一个整数 $A_i$。

对于从 $N$ 个球中选取若干球的一种方式，将该选择的**得分**定义为所选球上数字之和的平方。

求从 $N$ 个球中选取 $K$ 个球的所有 $\binom{N}{K}$ 种方式的得分之和（取模 $998244353$）。

### 约束条件

-   $1 \leq K \leq N \leq 2\times 10^5$
-   $1 \leq A_i \leq 10^9$
-   所有输入值均为整数。

* * *

### 输入

输入通过标准输入提供，格式如下：

```
$N$ $K$
$A_1$ $\dots$ $A_N$
```

### 输出

输出答案。

* * *

### 样例输入 1

```
3 2
1 10 100
```

### 样例输出 1

```
22422
```

从三个球中选出两个球共有三种方式：选择球 $1,2$ 得分为 $(1+10)^2=121$，选择球 $1,3$ 得分为 $(1+100)^2=10201$， 选择球 $2,3$ 得分为 $(10+100)^2=12100$。

答案是这三者的和，即 $121+10201+12100=22422$。

* * *

### 样例输入 2

```
5 2
10 10 20 20 20
```

### 样例输出 2

```
10600
```

多个球上可能标有相同的数字。

* * *

### 样例输入 3

```
2 1
998244353 998244353
```

### 样例输出 3

```
0
```

求该和模 $998244353$ 的余数。
