#### 问题陈述

在一条数线上的 $N$ 个位置上有一块饼干。第 $i$ 个 cookie 的坐标是 $A_i$ 。

高桥最初在数线上的坐标 $0$ 处，并重复下面的操作，直到他拾取了所有的 $N$ 块饼干。

- 操作：移动到离他当前位置最近的饼干坐标处（如果有多个这样的饼干，则移动到坐标最小的那个），并拾取该饼干。

求高桥拾取所有饼干前的总路程。

### Constraints

-   $1 \leq N \leq 3\times 10^5$
-   $-10^9 \leq A_i \leq 10^9$
-   $A_i\neq 0$
-   The $A_i$ are distinct.
-   All input values are integers.

### Input

The input is given from Standard Input in the following format:

```
$N$
$A_1$ $\dots$ $A_N$
```

### Output

Output the answer.

### Sample Input 1

```
4
-1 -4 2 -11
```

### 输出示例 1

```
23
```

高桥的操作如下。

-   他从坐标 $0$ 移动到坐标 $-1$，并捡起饼干。移动距离为 $1$。
-   他从坐标 $-1$ 移动到坐标 $-4$，并捡起饼干。移动距离为 $3$。
-   他从坐标 $-4$ 移动到坐标 $2$，并捡起饼干。移动距离为 $6$。
-   他从坐标 $2$ 移动到坐标 $-11$ 并捡起饼干。移动距离为 $13$。

因此，总移动距离为 $1+3+6+13=23$。

在第二次行动中，到坐标 $-4$ 处饼干和坐标 $2$ 处饼干的距离均为 $3$，而高桥移动到了坐标较小的 $-4$ 处。

### Sample Input 2

```
10
1 2 3 4 5 -1 -2 -3 -4 -6
```

### Sample Output 2

```
17
```
