### 问题陈述

有一个充电器，其充电槽数量不限。在时间 $0$ 时，所有充电槽均为空。

电池的最大容量为 $V$。当电池插入充电槽时，它将以速率 $1$ 进行充电，直到电量达到最大容量（即每经过 $1$ 个时间单位，电量增加 $1$）。

按顺序处理 $Q$ 个查询。第 $q$ 个查询采用以下格式之一给出。在此，保证 $t_1 < \dots < t_Q$。

-   类型 $1$ ($1\ t_q\ w_q$)：在时间 $t_q$ 时，将电量为 $w_q$ 的电池插入一个插槽。
-   类型 $2$ ($2\ t_q$)：在时间 $t_q$ 时，从插槽中拔出一块电量最高的电池，并输出该电池的电量。如果所有插槽中均未插入电池，则输出 $-1$。

### Constraints

-   $1 \leq Q \leq 3 \times 10^5$
-   $1 \leq V \leq 10^9$
-   For type $1$ queries, $1 \leq t_q \leq 10^9$.
-   For type $1$ queries, $0 \leq w_q \leq V$.
-   For type $2$ queries, $1 \leq t_q \leq 10^9$.
-   $t_1 < \dots < t_Q$
-   The input values are all integers.

### Input

The input is given from Standard Input in the following format:

```
$Q$ $V$
$\mathrm{query}_1$
$\vdots$
$\mathrm{query}_Q$
```

Here, $\mathrm{query}_q$ represents the $q$\-th query, and is given in one of the following two formats:

```
$1$ $t_q$ $w_q$
```
```
$2$ $t_q$
```

### Output

Let $x$ be the number of type $2$ queries. Output $x$ lines.

The $k$\-th line ($1 \leq k \leq x$) should contain the value to be outputed for the $k$\-th type $2$ query.

### Sample Input 1

```
7 100
1 15 60
1 25 80
2 30
1 45 0
2 60
2 70
2 80
```

### 样本输出 1

```
85
100
25
-1
```

这七个查询按以下顺序处理。

- 时间 $15$ 时，插入了充电等级为 $60$ 的电池。此时，充电器的电池电量为 $60$ 。
- 在时间 $25$ 处，插入一块电量为 $80$ 的电池。此时，充电器的电池电量为 $70, 80$ 。
- 在 $30$ 时，充电器中的电池电量为 $75, 85$ 。其中，电量为 $85$ 的电池已拔出。
- 在时间 $45$ 时，插入了电量为 $0$ 的电池。此时，充电器的电池电量为 $0, 90$ 。
- 在 $60$ 时刻，充电器的电池电量为 $15, 100$ 。其中，电量为 $100$ 的电池已拔出。
- 在 $70$ 时刻，充电器有一个电量为 $25$ 的电池。电量为 $25$ 的电池已拔出。
- 在时间 $80$ 时，充电器没有插入任何电池。因此，没有电池被拔下。
