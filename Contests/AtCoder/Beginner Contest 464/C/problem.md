#### 问题陈述

高桥在 $M$ 天里观察了 $N$ 只鸟，编号为 $1, 2, \dots, N$ 。  
高桥观察到的每只鸟都有 $N$ 种颜色，编号为 $1, 2, \dots, N$ ，这些鸟有一个有趣的特点：它们的颜色在观察期间会发生变化。

$i$ 在 $D_i - 1$ 天或之前观察到的颜色为 $A_i$ ，而在 $D_i$ 天或之后观察到的颜色为 $B_i$ 。  
这里，如果是 $D_i = 1$ ，则该鸟在 $1$ 日观察到的颜色为 $B_i$ ；如果是 $A_i = B_i$ ，则该鸟在观察期间颜色没有变化。

针对每种 $j = 1, 2, \dots, M$ ，求出 $j$ 天不同颜色的鸟的数量。

#### 限制因素

- $1 \le N \le 3 \times 10^5$
- $1 \le M \le 3 \times 10^5$
- $1 \le A_i, B_i \le N$
- $1 \le D_i \le M$
- 所有输入值均为整数。
