# 16、字母组合 charcom
## 题目描述
字母 A、B、C 的所有可能的组合（按**字典序**排序）是：A,AB,ABC,AC,B,BC,C。

每个组合都对应一个编号，如下表：
编号|组合
---|---
1  |A
2  |AB
3  |ABC
4  |AC
5  |B
6  |BC
7  |C

现在，给定一个组合 s，请找出它的编号。保证$s_i<s_{i+1}$

## 输入格式
$$
N\\S
$$
其中，$N$代表组合$S$是由前$N$个字母表组成的，$S$代表那个组合。
## 输出格式
$$
id
$$
其中，$id$代表$S$所对应的序号。
## 样例
输入：
``` 
3
AB
```
输出：
```
2
```
## 数据范围
$N\le 26, |S|\le N$
